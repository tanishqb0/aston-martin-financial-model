# Aston Martin Financial Model

## Overview

This project is an Excel-based financial model and investment analysis of Aston Martin Lagonda.

The model uses Aston Martin's published annual reports to analyse historical financial performance and forecast the company's financials from 2026 to 2030.

## Model Structure

The model currently includes:

- Historical financial analysis (2022–2025)
- Revenue and operating performance analysis
- Five-year financial forecast (2026–2030)
- Revenue driver assumptions based on wholesale volumes and average selling price
- Gross margin and operating cost assumptions
- Operating cash flow and free cash flow forecasting
- Capital expenditure forecasting
- Net debt and interest schedule

## Key Forecast Drivers

The forecast is based on a number of operating assumptions, including:

- Wholesale vehicle volumes
- Average selling price (ASP)
- Other revenue
- Gross margin
- Adjusted operating expenses
- Depreciation & amortisation
- Capital expenditure
- Working capital
- Interest rate on net debt

## Purpose

The objective of the project is to assess Aston Martin's financial outlook and ultimately estimate its intrinsic value using a discounted cash flow (DCF) valuation.
